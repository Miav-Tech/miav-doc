A API do CSMS (Charging Station Management System) da Miav expõe a gestão da
rede de recarga: estações e seus conectores, sessões de carregamento, grupos,
organizações e o tráfego OCPP das estações, tudo sob o mesmo serviço.

A URL base de produção é `https://api.miav.com.br`. As rotas REST e a conexão
WebSocket OCPP das estações compartilham essa mesma origem.

<Card title="API Reference" icon="code">
  Todos os endpoints estão na aba **API Reference** acima, com schemas de
  entrada e resposta gerados a partir do OpenAPI do serviço.
</Card>

## Autenticação

As rotas de painel exigem sessão autenticada via `/auth/*`. As estações se
autenticam na conexão OCPP com as credenciais cadastradas para cada
identificador de estação.

## Ambientes

O spec publicado aqui é gerado do código a cada mudança na branch principal do
serviço, então a referência reflete o contrato que está em produção.
